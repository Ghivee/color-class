Privacy Policy

Color Class Uploader. Effective 27 November 2026.

Who uses this tool

Only the owner of the Color Class YouTube channel.

Google user data accessed

With the owner's consent, the tool uses YouTube API Services to manage the channel: listing, uploading, scheduling and updating videos, reading comments, and reading YouTube Analytics reports such as views, watch percentage, likes, comments and subscribers gained.

How the data is used and stored

Data is used only to publish videos and to review their performance. The sign-in token, video IDs and statistics are stored in files on the owner's own computer and storage drive. There is no separate server or database.

Sharing

Data is not sold, shared with third parties, or used for advertising.

The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time at Google Account permissions. Deleting the local files removes the stored token and statistics.

Related terms

Use of this tool is subject to the YouTube Terms of Service. See also the Google Privacy Policy.
