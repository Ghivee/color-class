Color Class Uploader

A private tool used by the owner of the Color Class YouTube channel to publish short educational videos about math and science.

What it does

  • Uploads the owner's videos to the owner's YouTube channel and schedules them.
  • Reads video statistics from the same channel to plan new topics.

The tool runs on the owner's own computer. It is not offered to the public and has no user accounts.
